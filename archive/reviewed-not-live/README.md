# Reviewed Not Live Archive

These files were reviewed as non-person-focused and uploaded to GitHub for safekeeping, but they are not part of the GitHub Pages gallery.

The live site is built only from `curated/`. The build script does not read this archive folder.

Contents:

- `images/`: reviewed images and Pixel Motion Photo containers that are not currently selected for the public gallery page.
- `videos/`: standalone reviewed videos from the Monday transfer that are not used by the gallery page.
- `manifest.json`: counts, source notes, and file paths for this archive.

Person-focused shots remain excluded from this repository archive.
